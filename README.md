# Belgian Junior Gliding Team - JWGC 2026

This is the official website and blog platform for the **Belgian Junior Gliding Team**. The website is designed to document our journey toward the **Junior World Gliding Championships (JWGC) 2026** in Aalen, Germany, and to keep supporters and sponsors informed.

## ✈️ About JWGC 2026
* **Location:** Aalen, Germany
* **Dates:** August 1st – 15th, 2026
* **Competing Pilots:** Virginie Valck, Edwige Colson, Michiel Haemels & Wannes Smits.
* **Goal:** Representing Belgium at the highest international level of junior soaring.

## 🚀 Features
* **Live Tracking:** Real-time monitoring of the Belgian pilots via an integrated FLARM tracker.
* **Competition Results:** Direct score updates via a SoaringSpot embed.
* **Sponsorship Hub:** Detailed information on how partners can support the team's logistics and infrastructure.
* **Daily Blog:** Updates, photos, and meteorological analyses during the championship.

## 🛠️ Tech Stack
This website is built using **Grav CMS**, a modern flat-file CMS that prioritizes speed and flexibility.
* **Engine:** [Grav CMS](https://getgrav.org/)
* **Templating:** Twig
* **Styling:** Custom CSS (Mobile-first optimization)
* **Architecture:** Flat-file (no database required)

## 📂 Project Structure
Key directories for development:
- `/user/themes/belgian-juniors/templates/`: Contains the Twig files for layout logic (e.g., `sponsors.html.twig`).
- `/user/pages/`: Contains the actual content in Markdown format.
- `/user/themes/belgian-juniors/images/`: Storage for team media, glider photos, and partner logos.
